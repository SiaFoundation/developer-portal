# Additional Resources

## Keep building

Next steps once the quickstart is working:

* **Go deeper in the docs** — the recipes cover [uploading from files](recipes/upload-from-file.md), [tracking progress](recipes/track-progress.md), [sharing objects](recipes/share-an-object.md), and [deletion](recipes/delete-objects.md), and the core concepts explain the [trust and deployment model](core-concepts/trust-and-deployment.md) underneath the SDK.
* **Get help shipping** — join the [Sia Discord](https://sia.tech/discord) for support from the Sia Foundation and other developers while you build.
* **Report SDK issues** — file bugs and feature requests on [GitHub](https://github.com/SiaFoundation). If something in these docs blocked you, that's a bug too — please report it.
* **Show us what you built** — share your app or integration in the Discord. Real applications directly shape SDK priorities.
